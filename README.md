# 🧠 Portafolio RAG IA — Asistente Local con IA

Asistente de inteligencia artificial 100% local construido con Ollama, ChromaDB, LangChain y FastAPI.

## ¿Qué hace?

- Lee PDFs y responde preguntas sobre ellos (RAG)
- Recuerda el historial de conversación
- Expone una API REST documentada
- Interfaz web tipo ChatGPT
- Agente que decide solo qué herramienta usar

## Stack tecnológico

| Herramienta | Uso |
|---|---|
| Ollama + llama3.1 | Modelo de lenguaje local |
| ChromaDB | Base de datos vectorial |
| LangChain | Framework RAG |
| FastAPI | API REST |
| sentence-transformers | Embeddings |
| DuckDuckGo Search | Búsqueda web del agente |
